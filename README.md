# 원하연 제빵 포트폴리오

제빵사 원하연의 개인 포트폴리오 페이지입니다. 의존성 없는 단일 HTML 파일로 되어 있습니다.

## 구성

| 섹션 | 내용 |
|---|---|
| Hero | 이름, 한 줄 소개 |
| 01 소개 | 자기소개 및 활동 수치 |
| 02 대표 작품 | 사워도우 · 크루아상 · 식빵 · 베이글 · 프레첼 · 타르트 |
| 03 경력 & 자격 | 경력 타임라인, 보유 자격 |
| 04 빵 테트리스 | 브라우저에서 바로 즐기는 미니 게임 |
| 05 연락 | 이메일 및 링크 |

## 빵 테트리스

7가지 테트로미노에 각각 빵을 배정했습니다.

| 블록 | 빵 |
|---|---|
| I | 🥖 바게트 |
| J | 🥐 크루아상 |
| L | 🥨 프레첼 |
| O | 🍞 식빵 |
| S | 🥯 베이글 |
| T | 🧁 컵케이크 |
| Z | 🍩 도넛 |

조작: `←` `→` 이동 · `↑` 회전 · `↓` 빠르게 내리기 · `Space` 한 번에 내리기 · `P` 일시정지
모바일에서는 화면 하단 버튼으로 조작합니다.

착지 예정 위치 표시(고스트), 다음 블록 미리보기, 레벨에 따른 낙하 속도 증가를 지원합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 빌드 과정이 없습니다.

```
git clone https://github.com/<username>/hayeon-bakery.git
cd hayeon-bakery
start index.html
```
